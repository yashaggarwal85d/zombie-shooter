# data/

Content instances (`.tres`) for the data-driven Resources: one subfolder per
kind, for example `weapons/`, `components/`, `enemies/`, `traps/`,
`experiments/` and `nights/`. The Resource class scripts that define their
fields live in `src/` beside the code that uses them.

Nothing here yet: the Resource classes are written during the prototype,
once their fields come from the GDD. See TECHNICAL_ARCHITECTURE.md.
